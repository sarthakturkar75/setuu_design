PRJ-2023-44

Concrete Curing Delays in Sub-Zero Climates

troubleshoot Root Cause

Thermal blankets utilized were rated for -5°C, but ambient temperatures dropped to -18°C unexpectedly, stalling hydration.

Impact

Schedule: +14 Days delay on milestone M3.
Cost: $45,000 for emergency heating eqpt.

fact_check Recommendation

Mandate dual-layer thermal insulation specification for all pours scheduled between Nov-Feb in Region B, regardless of baseline forecast.

PRJ-2022-89

Crane Rigging Failure During Wind Gusts

troubleshoot Root Cause

Anemometer on tertiary crane was miscalibrated. Wind speeds exceeded safe operational thresholds (45km/h) but were registered as 30km/h.

Impact

Safety: Near miss (dropped load). Site evacuated.
Critical Incident Report filed.

fact_check Recommendation

Implement mandatory daily anemometer calibration checks logged via the mobile app before operational start. Require secondary ground-level wind sensors.

PRJ-2024-02

Vendor Scope Creep on HVAC Installation

troubleshoot Root Cause

Initial contract lacked specific line-item definitions for post-install duct testing, leading the vendor to classify it as an extra billing item.

Impact

Cost: $82,000 budget overrun on MEP phase.
Legal: Contract dispute resolved via arbitration.

fact_check Recommendation

Update standard MEP vendor template (v3.1) to explicitly include commissioning and duct pressure testing within the base bid.
