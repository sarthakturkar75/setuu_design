FIRM-492 sync In Progress

Optimize Sensor Polling Loop

Created: 2 days ago Reporter: Sarah Jenkins

Technical Specification

The current implementation of the I2C_Read() function in thermal_sensor.c is causing bus contention when multiple sensors are polled rapidly. This leads to intermittent communication failures (Error Code: 0x4F) documented in bug #112.

// Current blocking implementation
while(I2C_Busy(I2C_PORT_1)); 
I2C_ReadBytes(ADDR_THERMAL, buffer, 4);

Requirement: Implement an exponential backoff strategy or transition to an interrupt-driven DMA approach for sensor reads.
